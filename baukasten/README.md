# Baukasten für Sprach-Apps

Vorlage, um die App „Слово за слово“ (Russisch) für **jede andere Sprache** nachzubauen: Englisch, Französisch, Portugiesisch, Spanisch, Italienisch und weitere.

**Eine Datei genügt:** [SPRACH-APP-BAUKASTEN.md](SPRACH-APP-BAUKASTEN.md)

## Benutzung

1. Neuen Projektordner anlegen und `SPRACH-APP-BAUKASTEN.md` hineinkopieren (oder das Repository als Referenz klonen).
2. Claude Code im Ordner starten und schreiben:

   > Lies SPRACH-APP-BAUKASTEN.md und baue die App für **Englisch**. Maskottchen: …

3. Claude stellt Rückfragen, legt einen Plan vor und baut Phase für Phase, mit Tests, Commit und Push nach jeder Phase.

## Inhalt

Auftrag und Regeln für Claude Code · Parameter und Rückfragen · Wiederverwendung des Referenzprojekts · Datenmodell und Prüfungen · Lernlogik inklusive Abwechslung · Audio-Pipeline mit **geprüfter Lizenztabelle** der Piper-Stimmen · Design und Barrierefreiheit · Maskottchen, Begrüßung, Lob, Einführung · sprachspezifische Anpassungen · Sicherheit · Recht und Datenschutz · Tests · GitHub und Netlify · Phasenplan · **gelernte Fehler und Fallstricke** · Abschlussbericht · Vorlagen (`CLAUDE.md`, Startprompts, Maskottchen-Brief, Handtest).
